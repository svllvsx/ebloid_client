<h1 align="center">Eblo.id Client</h1>

Кроссплатформенный мобильный медиаклиент для просмотра каталога и работы с контентом.

Это публичная витрина проекта. Исходники, актуальные сборки и инструкции находятся в [оригинальном репозитории](https://github.com/svllvsxprod/ebloid_client). Полная копия исходного README сохранена [здесь](README.md).

**Темы:** `media-client`, `mobile-app`, `media-library`
